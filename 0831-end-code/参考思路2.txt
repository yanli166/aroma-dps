## 一、P0：必须完成，否则后续结果不能用于正式论文

### 1. 重构数据划分协议：固定20% final holdout

**优先级：P0**

**必要性：最高，属于实验有效性问题。**

当前代码中：

```python
canonical_splits(n, seed=seed, groups=data["smiles"])
```

会使不同seed生成不同测试集，同时seed还控制模型初始化，因此当前5-seed的mean±std混合了：

* 数据划分随机性；
* 参数初始化随机性；
* batch shuffle；
* dropout等训练随机性。

正式实验必须修改为：

[
D =
D_{\mathrm{dev}}(80%)
+
D_{\mathrm{test}}(20%)
]

其中20%测试集只生成一次，并在所有 Stage 1–4 中保持完全固定。

请增加类似：

```python
SPLIT_SEED = 2026
MODEL_SEEDS = [11, 22, 33, 44, 55]
```

要求：

```python
final_holdout = make_final_holdout(
    groups=canonical_molecule_id,
    test_size=0.20,
    seed=SPLIT_SEED
)
```

将split永久保存，例如：

```text
splits/
├── final_holdout_seed2026.json
└── development_indices.json
```

后续任何实验不得重新生成final test。

**验收标准：**

同一个任务中，不管model seed是多少：

```python
test_indices(seed=11)
==
test_indices(seed=22)
==
...
```

必须恒为True。

### 3. 分组ID由原始SMILES升级为canonical molecular identity

**优先级：P0**

**必要性：非常高，防止同一分子不同SMILES形式跨split。**

当前：

```python
groups = data["smiles"]
```

方向正确，但需要改成：

```python
canonical_smiles
```

或更稳妥：

```python
InChIKey
```

建议：

```python
def canonicalize_smiles(smi):
    mol = Chem.MolFromSmiles(smi)
    if mol is None:
        raise ValueError(...)
    return Chem.MolToSmiles(
        mol,
        canonical=True,
        isomericSmiles=True
    )
```

最终：

```python
groups = df["smiles"].map(canonicalize_smiles)
```

增加自动检查：

```python
assert set(train_groups).isdisjoint(set(test_groups))
```

并检查每个CV fold：

```python
assert set(train_groups).isdisjoint(set(val_groups))
```

# 十五、最重要的总原则

此次修改的目标不是让R²变得更高，而是让每一个结果都能够回答一个明确的科学问题。

最终Fig.3应该建立：

[
\boxed{
High\ IID\ learnability
}
]

↓

[
\boxed{
Target\ ring\ identity\ provides\ useful
chemical\ inductive\ bias
}
]

↓

[
\boxed{
The\ gain\ does\ not\ simply\ arise
from\ a\ more\ complex\ readout
}
]

↓

[
\boxed{
The\ effect\ transfers\ across
multiple\ GNN\ backbones
}
]

而Fig.4进一步回答：

[
\boxed{
High\ random\ split\ accuracy
\neq
chemical\ extrapolation
}
]

整个代码修改、实验设计、数据划分和结果输出都必须围绕这条论文逻辑服务，而不是为了保留原有Stage结构而强行证明每个模块都有提升。

在开始大规模重跑之前，请先完成**代码审计 → split重构 → bug修复 → 单元测试 → 小规模dry run**。只有所有验证通过后，才开始正式全量实验。
