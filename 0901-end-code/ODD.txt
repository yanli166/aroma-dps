# 25. 数学解释

如果：

pred_A_i =
true_A_i + b_g + epsilon_i

pred_A_j =
true_A_j + b_g + epsilon_j

那么：

pred_A_i - pred_A_j

=
true_A_i - true_A_j
+
epsilon_i - epsilon_j

共同 scaffold bias：

b_g

被抵消。

这为：

relative substituent effect

可能比：

absolute aromaticity

更 transferable 提供解释。

# 40. Monotonicity constraint 的正确评价

M2 不能只比较 MAE。

至少比较：

* MAE
* Spearman rho
* sign consistency
* monotonicity violation rate

定义：

对于两个 substituents a,b：

如果 Hammett electronic ordering 给出：

σ_a > σ_b

并且该 descriptor 在该 matched chemical context 的方向关系预先定义，

则检查 prediction ordering 是否一致。

---

# 41. 不要未经验证就假设 Hammett 与三个 aromaticity descriptor 同方向

这是重要原则。

执行 AI 必须先使用：

TRUE lunci10 labels

分析：

σ → ΔHOMA
σ → ΔNICS
σ → ΔMCBO

实际关系。

只有真实数据本身存在稳定 ordering：

才可以对 prediction 加相应 monotonicity constraint。

禁止先假定：

electron withdrawing substituent

必然让 HOMA/NICS/MCBO 单调朝某方向变化。

# 42. 这一步属于 chemical discovery，不是 label leakage

### monotonicity model

不能从完整 lunci10 test labels 学出来。
